# Stage 2 task: Time Series Analysis of air raid alerts in Ukraine

*Source: the KSE Agentic AI School Stage 2 invitation, paraphrased without personal details or links.*

## Goal
Build a small Python pet project that solves a real defense problem: **time series analysis of air raid alerts in Ukraine**.
AI is meant to be the main engineering tool here, not an add-on. Domain expertise is not expected, and AI should be used to fill that gap.

## Data and evaluation rules
- Work with the **most recent data available** and **evaluate on the latest period**.
- **No data leakage:** nothing the model trains on or takes as input may come from after the time the forecast is made.

## Optional: text and media data
Going beyond the alert history (news, official statements, public Telegram channels) is encouraged but not required.
The same leakage rule applies: use only content that was published before the forecast time.

## Submission (three parts)
1. **Artifact:** a link to the GitHub repository with the final, working Python code.
2. **AI log:** a full text export of the conversation history with the AI tool.
3. **Reflection:** about 100 words of plain text answering three questions:
   - What went wrong?
   - How did you adjust your approach?
   - Why is the final version better than the first attempt?

## Deadline
Monday, 12 October 2026, 23:59 Kyiv time (EEST).

## How it is evaluated
The **process** is evaluated, not just the result, and the AI interaction log is the primary signal. Reviewers look for active iteration, catching model hallucinations, fixing errors, and steering the AI toward a working architecture instead of accepting its first output.
